# FretCase 设计

完整的在线版设计文档在 Claude Docs 中维护，本文是同步进仓库的版本（2026-11-19）。3D 模型见 [model/index.html](model/index.html)。

## 概要

FretCase 是一只打开就能写歌的复古皮箱：箱盖里是 iPad，箱底是实体控件。用户用哼唱、环境声、照片或一段文字做起点，几分钟内做出一首歌，并印成一张扫码就能播放的卡片带走。

- **和 FretStudio 的关系**：沿用和声引擎（HRE）、可弹性求解（ACS）、备选生成和离线流程；去掉学习者档案和练习晋级。重点从"学编配"换成"做自己的歌"。
- **和一键生成的区别**：生成拆成几步，每一步都有实体控件，用户可以逐段、逐音轨地改。
- **不要求乐理**：控件叫"明暗、简繁、疏密"，背后对应调式、和弦词汇和节奏密度。
- **外观**：棕色皮革、胡桃木面板、黄铜五金、墨绿绒内衬。
- **投稿目标**：UIST 2027 demo（维也纳，2027 年 10 月 27–29 日；demo 截稿日未公布，往年在 7 月初）或 TEI 2028。

## 使用场景

一位不会乐器的旅行者在海边坐下，打开箱子，十分钟后带走一张属于这个地方的歌曲卡片。

1. **采集**：按住红色采集键哼八小节，再录十秒海浪，拍一张傍晚的海。
2. **种子卡**：屏幕给出一张可改的卡片，写着调、速度、情绪、旋律动机和音色。用户把速度调慢一点，确认。
3. **生成**：设备给出一版。不满意就按"换一个"，后悔了按"撤销"。
4. **调整**：转动唱盘到中间那一段，再按"换一个"只换这一段。鼓太吵，把鼓的推子拉低。有个音哼歪了，在屏幕上往上拖一格。
5. **印卡**：在屏幕上选水墨风格，预览满意后打印。出来一条不干胶，对折贴在一张空白硬卡上：正面是画，背面是二维码。
6. **带走**：卡片立在卡片架上当封面。朋友用手机扫码，能听到这首歌，看到真实的照片、城市和他写的一句话。

会场演示用同一流程，压缩到 3 分钟。

## 外观与布局

面板上每种形状只表示一件事：彩色方键是音轨，推子是音量，旋钮是整首歌的感觉，奶油色圆键是动作。

| 位置 | 部件 | 作用 |
| --- | --- | --- |
| 箱盖内侧 | iPad 11 寸 | 种子卡、谱面、改音符、卡片预览；自带麦克风和扬声器 |
| 箱盖背面 | 后置镜头的开孔和滑盖 | 拍风景；开孔在箱盖一角 |
| 箱盖内侧 | iPad 前置镜头 | 扫卡片背面的二维码 |
| 面板左侧 | 唱盘和 16 颗灯的灯环 | 转动唱盘在歌里前后移动，灯环一圈是整首歌 |
| 面板左下 | 采集、播放、撤销、换一个 | 四个圆键，采集键是红色 |
| 面板右上 | 四个旋钮 | 明暗、简繁、疏密、速度 |
| 面板右中 | 六路小调音台 | 每条音轨一个彩色方键和一个音量推子 |
| 面板右下 | 卡片仓和卡片架 | 放空白硬卡和印好的卡；当前这首歌的卡立在架上 |
| 箱子右侧 | 充电口、耳机口、总音量滚轮、电源开关与指示灯、出卡口 | |
| 箱底夹层 | Raspberry Pi、控制板、打印机、充电宝 | 运算、读控件、打印、供电 |

摄像头用 iPad 自带的两个。后置镜头的开孔要比镜头大一圈并向外扩（喇叭口），否则广角画面边缘会被孔壁挡住；滑盖在合箱搬运时保护镜头，也是物理隐私开关。看屏幕时箱盖后仰约 100°，拍照时要把箱盖立直。

模型按 320 × 240 × 100 毫米（合箱）搭建，这是假设值。iPad 11 寸机身 248.6 × 179.5 × 7 毫米，占箱盖内宽约 80%。

## 控件

| 控件 | 操作 | 功能 |
| --- | --- | --- |
| 采集键 | 按住哼唱或录音；短按拍照 | 生成种子卡；唱盘停在某一段时按住重哼，只替换这一段 |
| 唱盘与灯环 | 转动 | 在歌里前后移动；编辑时默认循环唱盘所在的那一段 |
| 播放键 | 按一下播放，再按停止 | 播放 |
| 换一个 | 按一下 | 对唱盘所在的那一段再给一个版本 |
| 撤销 | 按一下 | 回到上一步 |
| 六个彩色方键 | 短按选中音轨；长按静音 | 旋钮和屏幕编辑作用在选中的音轨上 |
| 六个推子 | 推拉 | 这一轨的音量 |
| 明暗旋钮 | 旋转 | 调式与情绪 |
| 简繁旋钮 | 旋转 | 和弦词汇的复杂度（对应 FretStudio 的 Basic / Explore / Colour） |
| 疏密旋钮 | 旋转 | 节奏型的密度（对应 FretStudio 的三级节奏分级） |
| 速度旋钮 | 旋转 | 速度 |
| 触摸屏 | 拖动、点按 | 改音符、改歌词、改种子卡、锁定、选卡片风格并预览 |
| 前置镜头 | 把卡片背面对着镜头 | 扫码载入并播放那首歌 |

六轨：人声、旋律、吉他、贝斯、鼓、环境声。

调整规则：

- **改个别音**在屏幕上做：音符显示为色块，上下拖改音高，左右拖改时值，默认吸附到调内音。
- **锁定**满意的段落或音轨，"换一个"不会动它们。
- **改歌词**：模型按旋律的音数写词，用户逐句改；字数变化时提示加减音符。
- **映射可见**：种子卡上每一项都写明来由，例如"画面偏暖，所以用大调"，并且可以逐项改。

已去掉的方案：16 个小节灯键、扫弦板、A/B 推子、段落键、循环键、拍速键、音阶键、NFC、拍立得。原因是功能重复，或者需要乐理知识才会用。

## 卡片与歌曲页

| 位置 | 内容 |
| --- | --- |
| 卡片正面 | 照片转成的水墨、漫画或写意画；没拍照就印歌名或一句和这首歌有关的话 |
| 卡片背面 | 二维码、歌名、城市、日期 |
| 扫码后的歌曲页 | 完整音频（含人声）、真实照片、城市、用户想说的话、歌词 |

- **制作**：热敏打印机出一条不干胶，前半段是画，后半段是二维码，对折包住一张空白硬卡。黑白的线条画和水墨正好适合热敏打印。
- **风格化**：联网时用图像生成模型；离线时用本地滤镜（描边、素描、网点）。打印前必须预览，用户确认后才出纸。
- **地点**：默认只到城市。来源是 USB GPS 模块，或者用户说一句地名。真实照片和地点放不放上歌曲页由用户选。
- **网址**：提前分配随机网址，没网时也能先印卡；联网后上传，页面随后生效。
- **回放**：把卡片背面对着 iPad 前置镜头，识别二维码后载入并播放。
- **不用 NFC 和拍立得**：音频在任何卡片上都存不下；NFC 相比二维码没有容量优势，手机读取更麻烦；拍立得相纸不能双面印。

## 声音

分轨谱面是唯一依据：每条音轨从谱面单独渲染，改一个音或一句词只重做那一轨的那一段。

| 环节 | 联网 | 离线 |
| --- | --- | --- |
| 和声候选 | 模型候选，HRE 打分 | 进行库与规则候选，HRE 打分 |
| 种子卡解析 | 多模态模型 | 颜色统计、关键词、节拍检测 |
| 歌词 | 模型按音数写词 | 用户自己写 |
| 人声 | 歌声合成 | 用户自己录的一轨，或不出人声 |
| 乐器与环境声 | 本地采样 | 本地采样 |
| 整曲渲染 | 端到端模型，可选 | 不提供 |

端到端生成模型音质好，但改不了单个音，所以只作为最后可选的整曲渲染。歌声合成候选：ACE Studio Vocal Synth、SoulX-Singer（开源）、Cantai API（接受 ABC），都未实测。

## 供电与充电

整只箱子只有一个充电口：插上一根 USB-C 线，箱内的充电宝和 iPad 一起充。

- **充电口**：右侧一个 USB-C 插座，接充电宝输入端。充电宝要支持边充边放。
- **iPad**：一根 USB-C 线经过箱盖铰链接到 iPad，从同一个充电宝补电。
- **iPad 只有一个接口**：充电和耳机音频共用，需要能同时充电和出音频的 USB-C 转接头，兼容性要实测。
- **电源开关**：拨杆开关加指示灯。关机时先让 Pi 正常关闭再断电，避免存储卡损坏。
- **电量显示**：第一版开小窗看充电宝自带的灯；以后换成能读电量的供电板，显示在屏幕上。
- **容量**：带上飞机一般不能超过 100 Wh（以航空公司规定为准），20000 mAh 约 74 Wh。
- **续航**：粗估大半天，待硬件到手后实测。

## 风险

| 风险 | 对策 |
| --- | --- |
| 户外哼唱转谱不准 | 转谱后先回放确认；按段重哼 |
| iPad 与 Pi 断开，面板失灵 | 两台都连自带的手机热点；断线后自动重连 |
| 联网渲染有延迟 | 只重渲染改动的音轨和段落；等待时用采样音色顶替 |
| Pi 上的性能未实测 | 第一周先在 Pi 上跑现有后端测耗时 |
| 风格化改动画面内容 | 打印前预览；保留"原图"选项 |
| 歌曲页暴露隐私 | 地点默认到城市；照片和地点可选；随机网址；上传前提示 |
| 二维码扫不出 | 码里只放短网址；用实物测试热敏纸对比度和镜头视野 |
| 打印时掉电 | 实测充电宝；会场演示接电源 |
| 声音授权 | 选型时读各家条款 |
