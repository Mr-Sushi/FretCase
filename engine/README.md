# engine

Harmony and arrangement core, ported from FretStudio: HRE scoring, ACS playability, capo, chord spelling, bass and drum generation. A plain Python library with no web framework. Owner: agent A. See ../docs/porting-from-fretstudio.md.

## Layout and tests

- `fretcase_engine/`: ported FretStudio modules (see `PORTED.md`) plus new code: `common`, `melody`, `harmonise`, `rhythm`, `accompaniment`, `generate`, `editing`, `export`, and `song_model` (generated by `sh engine/gen_song_model.sh`).
- Tests: `uv run pytest engine/tests/ported` (ported FretStudio tests) and `uv run pytest engine/tests --ignore=engine/tests/ported` (new).
